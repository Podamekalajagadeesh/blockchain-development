
# Day 04 - Blockchain Wallet Cryptography

## Objective
Understand blockchain wallets and digital signatures.

## Features
- Generate secp256k1 key pairs
- Create demo wallet identifiers
- Sign transactions
- Verify digital signatures
- Detect transaction tampering

## Technology
- JavaScript
- Node.js
- Crypto module

## Run
node wallet.js

## Note
This is an educational cryptography simulation,
not a production Ethereum wallet.
